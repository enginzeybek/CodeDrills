# CodeDrills 💻

This repository is a collection of coding exercises in multiple programming languages.

---

### 🎯 Purpose

The main goal is to improve problem-solving skills by focusing on logic rather than complex tools or libraries.

---

### 🧠 Approach

- Write clean and simple code.
- Focus on understanding the logic.
- Avoid unnecessary complexity.
- Solve one problem at a time.

---

### 🛠️ Languages

1. C#
2. Javascript
3. Python

---

### 📂 Structure

***Each language has its own folder, and problems are solved step by step.***

---

### 📈 Topics Covered

- Variables
- Conditions
- Loops
- Arrays / Lists
- Basic Algorithms

---

### 🚀 Workflow

1. Solve a problem
2. Write the code
3. Review and improve

---

### 🚀 Examples

```C#
//C#

//Değişken Tanımlama
int number = 10;
string name = "Engin";

//Koşul (If-Else)
if (number > 0)
{
    Console.WriteLine("Positive");
}
else
{
    Console.WriteLine("Negative or Zero");
}

//Döngü (For Loop)
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

//Dizi / Liste
int[] numbers = {1, 2, 3};

//Dizide Dolaşma
foreach (int num in numbers)
{
    Console.WriteLine(num);
}

//Basit Fonksiyon
int Add(int a, int b)
{
    return a + b;
}
```
